# Release 0.5.1

This release fixes two problems in the Compose deployments that break a
participant's connectors after a restart or when they look up their own
identity. Packages, images, Compose artifacts, and Helm charts share version
`0.5.1`.

## Fixes

- **Connectors could not resolve their own DID over HTTPS.** The participant's
  public gateway also used the public and DID host names as aliases on the
  private participant network. The control plane and data plane resolve
  `did:web` over HTTPS, so a lookup of their own DID (for example when the data
  plane refreshes an EDR token) reached the plain-HTTP gateway on port 443 and
  failed. This affected every Compose participant with HTTPS, tunnelled or
  behind its own proxy. The gateway now keeps only its role-scoped aliases on
  that network; the connectors reach their own host names the way other
  participants do. The local Compose stack, which uses plain HTTP, is
  unchanged.
- **Restarts could revoke the Vault app token.** The Vault bootstrap of the
  local Compose stack (also used by Compose operators built from it) and of
  the local Kubernetes setup revoked the application token on every run and
  created it again under the same ID. Vault could complete the revocation
  after the new token existed, so services lost access to all secrets a few
  minutes after a restart. The bootstrap now keeps a valid token and creates a
  periodic one only when it is missing, so it no longer expires after Vault's
  default 32 days while services renew it.

## Known issues

- BDRS 0.6.0 once answered 404 on `/api/check/readiness` after its first start
  on an upgraded operator, which kept the console from starting. Restarting
  `bdrs-server` resolved it.
- Running the local `bootstrap.sh` again on a stack that is already set up
  fails: Tractus-X EDC 0.13.0 answers a repeated policy definition with HTTP
  400 ("Policy Definition is referenced by a Contract Definition") instead of 409.

## Upgrade

Select matching `0.5.1` images and deployment artifacts. No database
migrations and no configuration changes.

**Compose participants:** update to the `0.5.1` participant package. Remove
any workaround that strips the public host aliases from the gateway's private
network.

**Compose operators and local stacks using the Vault bootstrap:** after the
update, run the stack once (`up -d --wait`). A token revoked by an earlier
restart is created again; a valid one is kept.
