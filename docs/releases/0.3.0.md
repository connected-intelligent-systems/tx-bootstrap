# Release 0.3.0

This release adds optional participant tunnels and the MkDocs documentation
site. Packages, images, Compose artifacts, and Helm charts share version
`0.3.0`.

## Changes

- Participants without public ingress can receive HTTPS traffic through an
  operator-managed Headscale/Tailscale tunnel. TLS terminates at the participant.
- The operator console issues tunnel keys with invitations, reports connection
  state, and supports replacement and revocation. Rejected participants lose
  tunnel access automatically; long-offline nodes are marked stale.
- New `tx-bootstrap-participant-tunnel` and `tx-bootstrap-tunnel` Compose
  artifacts, plus optional tunnel settings in the Helm charts.
- Participant request limits and ingress connection limits for shared tunnels.
- Searchable documentation on GitHub Pages, with shorter guides and corrected
  deployment, API, and version examples.

## Upgrade

Select matching `0.3.0` images and deployment artifacts. Run the normal database
migrations when upgrading the operator; they add tunnel enrollment metadata.

Tunnel support is disabled by default and requires an external Headscale
server, public ingress, and DNS configuration. See
[Participant tunnel](../participant-tunnel.md) for setup. Preserve tunnel node
identity and certificate storage across upgrades.

See the [documentation site](https://connected-intelligent-systems.github.io/tx-bootstrap/)
for the updated guides.
