# Release 0.3.1

This patch fixes gaps found when deploying the 0.3.0 operator on a fresh
server. Packages, images, Compose artifacts, and Helm charts share version
`0.3.1`.

## Changes

- The published Compose artifacts default to the matching repository images,
  so the image settings (`OPERATOR_CONSOLE_IMAGE` and others) are optional.
- The operator console reaches the issuer's issuance API through the public
  issuer host (`/api/issuance/*`) by default. Set `ISSUER_ISSUANCE_URL` to
  override it.
- With `OPERATOR_CONSOLE_AUTH_MODE=api-key`, the console asks for the API key,
  keeps it for the browser tab only, and asks again when the key is rejected.

## Upgrade

Select matching `0.3.1` images and deployment artifacts. No database
migrations. Deployments that pinned image settings or `ISSUER_ISSUANCE_URL`
only to work around 0.3.0 can remove those settings.
